# Barbershop-Booking-System

I created this react app for a barber client. Within this app I have implemented a menu where all the services offered are mentioned, a section detailing facts about the shop ie.location, contact details. I then added booking system for the barber to make managing haircuts and timings much easier for them as well as an admin page featuring a personalised calendar and a page to accept and decline bookings. Finally I created a contact me section where customers for the barber may make use of in order to find further information.

Future development of this app will include:
  Taking payments on the website
  Conformation to customers rather than only the barber
  Reminders of an appointment to customers close to the time 


  As of right now the website is hosted on netlify as development has not yet been fully completed: 'blends.netlify.app'
